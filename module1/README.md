# Module 1 — USB Forensics Artifact Collection

This module collects and examines Windows USB forensic artifacts.

## Components
- USB connection and disconnection monitoring
- USBSTOR registry artifacts
- MountPoints2 registry artifacts
- SetupAPI device-installation logs
- Windows Security Event Log
- Recent Windows shortcut (`.lnk`) artifacts

## Technology
- Python
- Windows Registry
- Windows Event Log
- WMI
- LnkParse3
